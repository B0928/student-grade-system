# 教务管理系统

一个基于 Python 控制台的简易学生成绩管理系统，采用三层分离设计：

- `student.py` —— 数据模型层：Student 类，封装单个学生的学号、姓名、成绩
- `grade_system2.py` —— 业务逻辑层：GradeSystem 类，负责增删改查、统计、持久化、报表
- `main.py` —— 界面层：控制台菜单与用户交互

## 安装

```bash
pip install -r requirements.txt
```

依赖：pandas、matplotlib、openpyxl、numpy（均为常用库，无版本强制要求）。

## 运行

```bash
python main.py
```

学生数据自动保存到同目录的 `students.json`，启动时自动加载。

## 功能列表

| 菜单 | 功能 |
|---|---|
| 1 | 添加学生（学号可自动生成，允许同名，靠学号区分） |
| 2 | 修改学生成绩（支持按学号或姓名定位，重名时会列出学号选择） |
| 3 | 删除学生（按学号删除，删除前需确认） |
| 4 | 查询学生（支持学号或姓名） |
| 5 | 显示所有学生 |
| 6 | 班级统计（各科平均分 / 及格率 / 总分排名） |
| 7 | 生成 Excel 表格（按总分降序，需 openpyxl） |
| 8 | 生成成绩分布图（按总分分低/中/高三区间的柱状图，保存为 PNG） |
| 9 | 保存数据 |
| 10 | 保存并退出 |

## 说明

- 成绩校验：单科成绩必须在 0-100 之间，非法输入会提示重输。
- 数据文件损坏时不会静默清空：程序会打印原因并把原文件备份为 `students.json.bak`。
- Excel 和 PNG 默认生成在程序运行目录，输入文件名时可带完整路径换位置。
